# 🩺 내 통증 사용설명서

동네 병원(정형외과·재활의학과)에서 가장 자주 진단되는 **근골격계 질환 40가지**를
재활 트레이닝·스포츠의학 관점에서 정리한 웹 전자책입니다.
고등학생 수준의 독해력이면 충분히 이해할 수 있는 쉬운 말로 풀었습니다.

## 구성

7개 부위 카테고리 × 40개 질환, 모든 질환은 같은 구조로 정리되어 있습니다.

| 섹션 | 내용 |
|---|---|
| 📖 어떤 질환인가요? | 질환의 정체와 원인을 비유로 쉽게 설명 |
| ✅ 증상 체크 | 눌러서 체크하는 인터랙티브 체크리스트 (실시간 집계, 진단 아님 안내) |
| 🔬 자가 관찰 | 임상 검사를 집에서 안전하게 살펴보는 방법 |
| 🤲 수동 치료 | 도수치료·물리치료 등 전문가가 해주는 치료 |
| 🏃 능동 치료 | 횟수·세트까지 제시된 단계별 셀프 운동 |
| 🚨 병원에 가야 할 때 | 자가 관리를 멈춰야 하는 위험 신호(red flag) |

### 주요 기능

- 🧍 **통증 부위 그림(body map)** — 인체 그림에서 아픈 부위를 눌러 바로 탐색
- ✅ **인터랙티브 증상 체크** — 항목을 체크하면 실시간 집계 (체크 개수만으로 질환을 판정하지 않음), 질환별 체크 상태가 저장되어 재방문에도 유지
- 🔠 **글자 크기 조절** — 헤더의 가A 버튼으로 3단계(100·112·125%) 조절, 선택 저장
- 🔎 **검색어 하이라이트** — 검색 결과에서 일치한 단어를 표시
- ⚖️ **질환 비교(vs 보기)** — 헷갈리는 두 질환(예: 테니스 엘보 vs 골프 엘보)을 나란히 놓고 증상·자가 관찰·치료·위험 신호를 한눈에 비교
- ⭐ **즐겨찾기 / 🕒 최근 본 질환** — localStorage에 저장되어 홈에서 이어 보기
- 🖨 **인쇄 / PDF 핸드아웃** — 치료사가 환자에게 1장으로 출력해 줄 수 있는 인쇄 스타일
- 🔍 **증상 키워드 검색** — 질환명·증상·원인 전체에서 매칭
- 📲 **SNS 공유 카드** — 카카오톡·트위터 등 OG 미리보기, 질환별 제목 동적 갱신
- ▶ **운동 영상 링크** — 능동 치료 운동마다 YouTube 검색 연결 (깨지지 않는 검색 URL)
- 📱 **PWA(앱 설치 · 오프라인)** — 홈 화면에 설치하고, 한 번 연 뒤엔 오프라인에서도 열람
- 🌐 **한국어 / English 이중 언어** — 헤더의 토글로 전환, 40개 질환 전체 영어 제공 (선택 언어 저장, 영어권 브라우저 자동 감지)

### 수록 질환 (40)

- **목 (5)** — 거북목/일자목, 목 디스크, 근막통증증후군(담 결림), 경추성 두통, 흉곽출구증후군
- **어깨 (6)** — 날개뼈 운동이상증, 어깨충돌증후군, 회전근개 건병증/파열, 오십견, 석회성 건염, 어깨 불안정증/탈구
- **팔꿈치·손목·손 (6)** — 테니스 엘보, 골프 엘보, 손목터널증후군, 드퀘르벵 건초염, 방아쇠 수지, 팔꿈치터널증후군
- **허리·골반 (6)** — 비특이적 요통, 허리 디스크, 척추관 협착증, 천장관절 기능장애, 이상근 증후군, 척추전방전위증
- **엉덩이·허벅지 (5)** — 고관절 충돌증후군(FAI), 대전자 통증 증후군, 햄스트링 부상, 발음성 고관절, 내전근 좌상
- **무릎 (6)** — 슬개대퇴 통증 증후군(러너스 니), 슬개건염(점퍼스 니), 장경인대 증후군, 무릎 골관절염, 반월상연골 손상, 전방십자인대(ACL) 손상
- **발목·발 (6)** — 발목 염좌/만성 불안정증, 족저근막염, 아킬레스 건병증, 정강이 통증(신 스플린트), 무지외반증, 후경골근건 기능부전(성인 평발)

## 기술 구조

빌드 과정이 전혀 없는 **순수 정적 사이트**(HTML + CSS + Vanilla JS)입니다.

```
index.html             # 단일 페이지 앱 진입점
css/style.css          # 전체 스타일 (인쇄용 @media print 포함)
js/app.js              # 해시 라우터 + 렌더러 + 검색 + body map + 저장/공유 + SW 등록
js/data/*.js           # 카테고리별 질환 콘텐츠 (한국어, 40개 질환)
js/data/en/*.js        # 영어 콘텐츠 (CONTENT_EN, 40개 질환)
manifest.webmanifest   # PWA 매니페스트
sw.js                  # 서비스 워커 (stale-while-revalidate 오프라인 캐시)
assets/                # OG·앱 아이콘 + 순수 Node 생성 스크립트
scripts/prerender.mjs  # 질환별 정적 페이지 + sitemap 생성기 (SEO)
condition/, en/condition/  # 생성된 질환별 정적 페이지 (검색엔진·SNS 공유용)
sitemap.xml, robots.txt    # 생성된 SEO 파일
```

### SEO 정적 페이지

해시 라우팅 SPA는 검색엔진에 한 페이지로만 보이므로, 질환별 정적 페이지를
미리 생성해 함께 배포합니다 (`/condition/<id>/`, `/en/condition/<id>/` +
canonical·hreflang·OG 태그·sitemap). **콘텐츠(js/data)를 수정하면 반드시
다시 생성해 커밋하세요:**

```bash
node scripts/prerender.mjs          # 배포 도메인이 다르면: SITE_URL=https://내도메인 node scripts/prerender.mjs
```

- 해시 라우팅: `#/category/neck`, `#/condition/tennis-elbow`, `#/compare/tennis-elbow/golfers-elbow`, `#/search/검색어`
- 증상 키워드 검색: 질환명·증상·원인 텍스트 전체에서 매칭
- 서버·DB·빌드 도구 불필요 — 정적 호스팅이면 어디서든 동작

## Vercel 배포

1. [vercel.com](https://vercel.com)에서 **Add New → Project**
2. 이 GitHub 저장소를 Import
3. Framework Preset: **Other**, Build/Output 설정은 모두 기본값(비워 둠)
4. **Deploy** — 끝. 빌드 단계가 없으므로 바로 배포됩니다.

로컬 미리보기:

```bash
npx serve .        # 또는
python3 -m http.server 8000
```

## ⚠️ 면책 안내

이 전자책은 건강 정보 제공을 목적으로 하며, 의료인의 진단과 치료를 대신할 수 없습니다.
각 질환의 "병원에 가야 할 때" 항목에 해당하거나 증상이 2주 이상 지속되면 의료기관을 방문하세요.

### 회귀 검사

`node --test tests/*.test.cjs`로 검색어 강조, 언어 전달, 오프라인 상세 경로를 검사합니다.
CI는 정적 페이지를 다시 생성한 뒤 커밋된 결과와 같은지도 확인합니다.
오프라인 상세 주소는 루트 기준 자원을 사용하는 SPA로 열리며, 영어 문서에서
인터랙티브 화면으로 이동할 때 `?lang=en`으로 언어를 전달합니다.
